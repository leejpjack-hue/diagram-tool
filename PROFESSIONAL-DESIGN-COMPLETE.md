## 🎓 Design System Features

### CSS Variables
All design tokens are CSS variables for easy theming:
```css
--primary-600: #4F46E5;
--spacing-lg: 16px;
--shadow-md: 0 4px 6px -1px rgba(0, 0, 0, 0.1);
--radius-md: 8px;
```

### Composable Classes
Mix and match classes for flexibility:
```html
<button class="btn btn-primary btn-lg">
  Large Primary Button
</button>
```

### BEM-like Naming
Clear, predictable naming convention:
```css
.btn           /* Block */
.btn-primary   /* Modifier */
.btn-lg        /* Modifier */
.card          /* Block */
.card-header   /* Element */
.card-title    /* Element */
```

### Responsive Design
Mobile-first approach with breakpoints:
```css
@media (max-width: 768px) {
  /* Mobile styles */
}
```

## 🔄 How to Use

### Using the Design System

**For existing components:**
No changes needed! The professional styles are automatically applied.

**For new components:**
Use the design system classes:
```html
<!-- Buttons -->
<button class="btn btn-primary">Primary Action</button>
<button class="btn btn-secondary">Secondary Action</button>

<!-- Cards -->
<div class="card">
  <h3 class="card-title">Title</h3>
  <p class="card-description">Description</p>
</div>

<!-- Badges -->
<span class="status-badge badge-success">Success</span>

<!-- Inputs -->
<input type="text" class="input" placeholder="Enter text...">
```

### Customizing Colors

**To change the primary color:**
```css
:root {
  --primary-600: #YourColor;
  --primary-700: /* Darker shade */;
  --primary-800: /* Even darker */;
}
```

### Adding New Components

**Follow the design system:**
1. Use CSS variables for colors
2. Use spacing variables
3. Use shadow variables
4. Follow naming convention
5. Add hover states
6. Add transitions
