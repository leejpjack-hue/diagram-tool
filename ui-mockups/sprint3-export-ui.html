7. Design Notes

Visual Style

  • Colors: Executive Heritage palette (navy, slate, indigo)
  • Typography: Inter for UI, JetBrains Mono for code
  • Spacing: 8px base unit, consistent throughout
  • Border radius: 8px for panels, 12px for modals
  • Shadows: Subtle elevation (0 4px 12px rgba(0,0,0,0.1))

File Naming Convention

{diagram-title}-{mode}-{date}.{format}

Examples:
- claims-platform-architecture-2026-02-17.png
- claims-processing-flow-2026-02-17.svg
- insurance-system-2026-02-17.json

Default Settings

  • PNG: 3x resolution (presentation quality), white background, grid included
  • SVG: Optimized, embedded fonts, CSS inline
  • JSON: Formatted with metadata

Quality Indicators

🖥️ Screen (1x) 📺 Retina (2x) 📊 Presentation (3x) 🖨️ Print (4x)
