6. Design Notes

Interactions

  • Click node: Properties panel shows node details with tabs
  • Click canvas (deselect): Show diagram overview stats
  • Double-click node: Focus and zoom to node
  • Edit property: Auto-save on blur, no save button needed

Tabs

  • Properties: Edit node name, type, technology, metadata
  • Style: Colors, borders, shadows, visibility options
  • Connections: Manage incoming/outgoing connections

Quick Actions

  • Copy: Copy node to clipboard (can paste with Cmd+V)
  • Duplicate: Create copy of node at offset position
  • Delete: Remove node and its connections (asks confirmation)

Keyboard Shortcuts

Delete/Backspace  - Delete selected node
Cmd/Ctrl + D     - Duplicate selected node
Cmd/Ctrl + C     - Copy node
Cmd/Ctrl + V     - Paste node
Escape           - Deselect node
